# Nim notes app

Same notes UI as the Bun [`notes-app`](../notes-app/) template, with a Nim main process.

From the `package/` folder in the Electrobun repository:

```bash
hutch dev:template nim-notes-app
```

Or run the local dev bundle directly (recommended until Hutch adds `mainProcess: "nim"`):

```bash
hutch run:nim-notes-app
```
