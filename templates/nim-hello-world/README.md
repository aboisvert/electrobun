# Nim hello world

Minimal Electrobun app with a Nim main process. See the
[hello world guide](https://electrobun.dev/electrobun/guides/hello-world-nim/).

From the `package/` folder in the Electrobun repository:

```bash
hutch run:nim-hello-world
```

Or with Hutch directly (after `hutch electrobun sync` in this directory):

```bash
hutch run dev
```
